# Full-Stack React & Django Project

A full-stack web application built with a **Django** backend (REST API) and a **React** frontend.

---

## 📋 Prerequisites

Make sure you have the following installed on your machine before starting:
* **Python** (v3.10 or higher) & `pip`
* **Node.js** (v18 or higher) & `npm`

---

## 🚀 Project Setup & Installation

Follow these steps to create and run the project locally.

Open your terminal and create a main folder to hold both the backend and frontend:
